# Habit Helper: Telegram-бот для отслеживания состояния и нежелательных привычек

Учебный проект по Python (НИУ ВШЭ).

> **Важно.** Бот не является медицинским инструментом и не заменяет специалиста.
> При сильном дискомфорте обратитесь к психологу или врачу.

## Зачем это нужно

Люди хотят снизить нежелательные привычки (например, залипание в телефоне), но
не видят связи привычки с состоянием и нагрузкой и составляют нереалистичные планы.

Бот собирает короткие структурированные данные, находит в них закономерности и
строит план дня по реальному самочувствию. LLM не используется: вся логика
алгоритмическая и объяснимая.

## Что умеет бот

- **Вечерний check-in:** настроение, энергия, стресс (1-10), был ли эпизод и сколько минут.
- **«Тянет»:** выбор триггера (скука, усталость, стресс) и силы импульса (1-5), бот
  предлагает технику из `techniques.json` и спрашивает «Помогло?». Со временем
  чаще предлагается то, что помогало.
- **Статистика за 30 дней:** средние, частые триггеры и наблюдения вида «в дни с высоким
  стрессом эпизоды случались в 80% таких дней». Наблюдения появляются при 7+ днях данных.
- **План на день:** бюджет нагрузки считается по последнему check-in, обязательные дела
  входят всегда, дела для развития выбираются жадно по приоритету на единицу нагрузки.

Формулировки осторожные («наблюдается связь»): корреляция не доказывает причину.

## Требования

- Python 3.10 или новее (разработка и проверка: Python 3.14, Windows)
- Аккаунт Telegram

## Установка (Windows, командная строка)

```
cd путь\к\папке\проекта
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск бота

1. Создайте своего бота: в Telegram откройте **@BotFather**, отправьте `/newbot`,
   задайте имя и username (заканчивается на `bot`). BotFather пришлёт токен.
2. Задайте токен и запустите (кавычек в `set` не нужно):

```
set BOT_TOKEN=токен_от_BotFather
python bot.py
```

3. Откройте бота в Telegram и отправьте `/start`.

Токен нельзя хранить в коде или выкладывать в репозиторий. Переменная живёт только
в текущем окне терминала, в новом окне её нужно задать заново.

### Если Telegram недоступен напрямую (необязательно)

Если сеть блокирует `api.telegram.org`, можно направить бота через HTTP-прокси:

```
set PROXY_URL=http://127.0.0.1:ПОРТ
python bot.py
```

Без `PROXY_URL` бот подключается напрямую.

## Демо-данные (необязательно)

Чтобы сразу увидеть статистику и наблюдения, создайте 30 дней синтетической
истории (по вчерашний день, сегодня остаётся свободным для check-in):

```
python seed.py ВАШ_TELEGRAM_ID
```

Свой числовой ID показывает бот **@userinfobot**. Параметры:
`--db файл.db` (по умолчанию `habit_bot.db`) и `--days N` (по умолчанию 30).
Если у пользователя уже есть данные, скрипт ничего не перезаписывает: удалите
файл базы и запустите снова.

Демо-данные **синтетические**: связь между стрессом, энергией и эпизодами заложена
в генератор. На реальных данных она может не проявиться.

## Тесты

```
python -m pytest
```

Тестами покрыты аналитика, планировщик, подбор техник, база данных и генерация демо-данных.

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `bot.py` | Telegram-бот (aiogram): меню, диалоги check-in и «Тянет», статистика, план |
| `models.py` | dataclass'ы: User, CheckIn, Impulse, Task, Plan, Technique |
| `db.py` | класс Database: SQLite (users, checkins, impulses) |
| `analytics.py` | средние, топ триггеров, корреляция, правила-наблюдения |
| `planner.py` | бюджет нагрузки и жадная сборка плана дня |
| `techniques.py`, `techniques.json` | загрузка техник и выбор лучшей по доле «помогло» |
| `seed.py` | генерация демо-данных |
| `test_*.py` | тесты pytest |

## Как это работает

- **Бюджет нагрузки** = 100 − 5·max(0, 6 − энергия) − 3·max(0, стресс − 5), не меньше 40.
  Без данных бюджет 100.
- **Выбор техники:** фильтр по триггеру и интенсивности; рейтинг = (помогло + 1) / (оценено + 2)
  (сглаживание Лапласа); с вероятностью 20% выбирается случайная подходящая техника.
- **Наблюдения:** нужно 7+ дней; группа «стресс ≥ 7» или «энергия ≤ 4» не меньше 3 дней и
  доля эпизодов выше общей минимум на 20 п.п.; корреляция Пирсона при 10+ наблюдениях и |r| ≥ 0.5.

## Ограничения

- Пороги в аналитике эвристические, не обучены на реальных данных.
- Задачи плана заданы шаблоном в коде (`DEFAULT_TASKS`), своих задач в MVP нет.
- Бот работает, пока запущен `python bot.py`.

- Оптимальный план через задачу о рюкзаке (динамическое программирование) вместо жадного.
